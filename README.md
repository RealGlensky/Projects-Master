# Project Portfolio

Welcome to my central project hub! Here is a list of some of my favorite built projects to-date. This covers projects built in, and with a combination of:
* Replit
* Claude Code
* Cursor
* Vercel

## 🚀 Top 3
*   [ourmealplan](https://ourmealplan.vercel.app) — (Private Repository) — A modern rebuild of ourmealplan.com: marketing site + meal planning app.
*   [Dreno](https://dreno-demo.vercel.app) — (Private Repository) — A mental performance platform for athletes.
*   [Fantasy Draft Copilot](https://fantasy-draft-copilot-inky.vercel.app) — (Private Repository) — A live NFL fantasy draft strategy tool with ADP-based value/reach detection, Sleeper draft sync, position-run forecasting, practice drafts vs AI and a trade analyzer.
